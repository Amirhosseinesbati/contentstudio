## Split and metrics

The 20 development validation cases use four source entities; the 60 held-out cases use the other eight. The generator writes answers under `evals/datasets`, not the model fixture index or prompt. The 70/70 figure is expected-warning recall on executed synthetic cases. Ten duplicate-publishing cases are integration-only rather than pure warning-checker cases; the API test exercises a repeated dispatch key, and the n8n/simulator replay verifies one 429-plus-duplicate path. The other planted duplicate cases and real WordPress behavior remain unverified. This dataset is deliberately templated and cannot establish live factual accuracy or transcription quality.
